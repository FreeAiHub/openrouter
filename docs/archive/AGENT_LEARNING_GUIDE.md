## 🤖 Типы Агентов в Claude Code

### 1. **general-purpose**
Для общих задач, поиска, исследования.

**Когда использовать**:
- Поиск информации в codebase
- Исследование архитектуры
- Ответы на вопросы "как работает X?"

**Пример**:
```
User: "Найди все функции, которые работают с API"
→ Запускает general-purpose агента
```

---

### 2. **Explore** ⭐
Быстрое изучение кодовой базы.

**Когда использовать**:
- "Как устроен проект?"
- "Где находится код для X?"
- "Какие файлы отвечают за Y?"

**Уровни thoroughness**:
- `quick` - быстрый обзор
- `medium` - умеренное изучение
- `very thorough` - глубокий анализ

**Пример**:
```
User: "Как устроена обработка webhooks?"
→ Запускает Explore агента
```

---

### 3. **Plan** 📋
Архитектор для планирования реализации.

**Когда использовать**:
- Перед началом большой задачи
- Нужен план имплементации
- Выбор между несколькими подходами

**Что делает**:
- Анализирует требования
- Предлагает архитектуру
- Создает step-by-step план
- Оценивает trade-offs

**Пример**:
```
User: "Нужно добавить систему кеширования"
→ Plan агент создаст детальный план
```

## 🔍 Анализ Работы Агента

### Что Агент Сделал Хорошо (Наш Пример)

#### 1. **Модульность**
```python
# Вместо одного большого файла:
manus_client.py (300 строк)

# Создал модульную структуру:
src/manus/
├── client.py      (350 строк) - только клиент
├── models.py      (180 строк) - только модели
├── exceptions.py  (100 строк) - только исключения
└── webhook.py     (250 строк) - только webhooks
```

**Почему это хорошо**:
- Легче читать
- Легче тестировать
- Легче поддерживать
- Следует Single Responsibility Principle

---

#### 2. **Типизация**
```python
# Было (без типов):
def create_task(prompt, context=None):
    return {...}

# Стало (с Pydantic):
def create_task(
    self,
    request: ManusTaskRequest
) -> ManusTaskResult:
    return ManusTaskResult(...)
```

**Почему это хорошо**:
- ✅ Автоматическая валидация
- ✅ IDE autocomplete
- ✅ Меньше багов
- ✅ Лучшая документация

---

#### 3. **Error Handling**
```python
# Было:
if response.status_code != 200:
    return {"error": "Failed"}

# Стало:
if response.status_code == 401:
    raise ManusAuthenticationError("Invalid API key")
elif response.status_code == 429:
    raise ManusRateLimitError("Rate limit exceeded")
elif response.status_code == 404:
    raise ManusTaskNotFoundError(f"Task {task_id} not found")
```

**Почему это хорошо**:
- ✅ Типизированные ошибки
- ✅ Понятные сообщения
- ✅ Легче отлавливать специфичные ошибки

---

#### 4. **Тестирование**

## 🎓 Ресурсы для Углубления

### Концепции из Нашего Проекта

1. **Pydantic Validation**
   - Документация: https://docs.pydantic.dev/
   - Что изучить: BaseModel, validators, Field

2. **HMAC Signatures**
   - Что это: Криптографическая подпись
   - Зачем: Проверка подлинности webhooks
   - Где используем: webhook.py

3. **Retry Logic & Exponential Backoff**
   - Что это: Повторная попытка при ошибке
   - Зачем: Надежность при сетевых проблемах
   - Где используем: client.py

4. **Circuit Breaker Pattern**
   - Что это: Защита от каскадных падений
   - Зачем: Fault tolerance
   - Где будем использовать: OpenRouter client
